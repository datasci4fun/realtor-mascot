# VRM Mascot Model

Place your VRM avatar file here as `mascot.vrm`.

## Getting a VRM Model

### Option 1: VRoid Hub (Free)
1. Go to https://hub.vroid.com/
2. Browse free VRM avatars
3. Download one you like
4. Rename to `mascot.vrm` and place in this folder

### Option 2: Create Your Own with VRoid Studio (Free)
1. Download VRoid Studio: https://vroid.com/en/studio
2. Create your custom avatar
3. Export as VRM
4. Rename to `mascot.vrm` and place in this folder

### Option 3: Ready Player Me
1. Go to https://readyplayer.me/
2. Create an avatar
3. Export as VRM format
4. Rename to `mascot.vrm` and place in this folder

## Recommended Settings

- Keep file size under 15MB for fast loading
- Use texture sizes of 1024x1024 or smaller
- Remove unused blend shapes to reduce file size

## Fallback

If no VRM is found, the mascot will display a friendly emoji placeholder.
