# Realtor Site - Future Features & Ideas

## Mortgage Calculator Enhancements

### Comparison Features
- [ ] **Side-by-side loan comparison** - Compare 2-3 loan scenarios at once (e.g., 15yr vs 30yr, or FHA vs Conventional)
- [ ] **Rent vs Buy calculator** - Compare monthly rent to buying costs, show break-even point
- [ ] **Refinance calculator** - Compare current loan to refinance options, show savings

### Extra Payments
- [ ] **Extra payment calculator** - Add monthly/yearly extra payments, show time/interest saved
- [ ] **Bi-weekly payments** - Show savings from paying bi-weekly instead of monthly
- [ ] **Lump sum payoff** - Calculate impact of one-time extra payments

### Affordability
- [ ] **How much can I afford?** - Input income/debts, calculate max home price based on DTI ratios
- [ ] **Debt-to-income calculator** - Show DTI ratio with the mortgage included
- [ ] **Closing costs estimator** - Estimate buyer closing costs (title, escrow, points)

### Local/Texas Specific
- [ ] **Texas property tax lookup** - Fetch actual tax rates by county/city
- [ ] **Homestead exemption calculator** - Show savings from Texas homestead exemption
- [ ] **Insurance estimator** - Estimate based on home value and location

### Visualization
- [ ] **Equity growth chart** - Show equity building over time
- [ ] **Total cost comparison bar chart** - Visual comparison of different scenarios
- [ ] **Printable/PDF summary** - Export calculator results

### Interactive
- [ ] **Save/share scenarios** - URL parameters to share specific calculations
- [ ] **Email results** - Send summary to yourself or client

## Client Portal Features

### Notifications
- [ ] **Price drop alerts** - Email when favorited properties drop in price
- [ ] **SMS notifications** - Text updates for viewings, messages
- [ ] **New listing alerts** - Notify when new listings match saved searches

### Search & Discovery
- [ ] **Saved searches** - Save search criteria, get notified when new listings match
- [ ] **Neighborhood pages** - Schools, walkability, market stats by area
- [ ] **Map-based search** - Draw boundaries to search within

### Documents & Transactions
- [ ] **Document upload** - Clients upload pre-approval letters, contracts
- [ ] **Offer tracker** - Track offers made, status, counteroffers
- [ ] **Closing checklist** - Step-by-step progress tracker for escrow
- [ ] **E-signature integration** - Sign documents within portal

### Calendar & Scheduling
- [ ] **Viewing calendar sync** - iCal/Google Calendar sync for scheduled viewings
- [ ] **Automated reminders** - Reminder emails/texts before viewings
